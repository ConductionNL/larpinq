# Who sees which character

Players see their own character sheet in full. Other characters appear to them as cast entries: a name, a type and a short description. Game masters see everything.

## What a player sees

| On their own character | On another approved character |
|---|---|
| Name, type, description | Name, type, description |
| Background and faith | Not shown |
| Public notes, card, notice | Not shown |
| Gold, silver, copper | Not shown |
| Skills, items, conditions, events | Not shown |
| Private game master notes: never | Not shown |

A character that is not approved yet stays hidden from other players. It does not show up in search either.

## What a player can change

On their own character, a player edits the name, the description, the background and the faith. Everything else stays with the game masters: money, skills, items, conditions, public notes and approval. A save that changes one of those fields is refused.

A player cannot change another player's character at all.

## The cast page

Open **Cast** in the menu to browse every approved character, sorted by name. Players use it to learn who they will meet at the next event.

## Game masters

Members of the `gamemasters` group read and edit every character, including the private notes. Nextcloud administrators can do the same.

## Creating a character

A game master creates characters in the app as before. A player who creates one in the app starts with the name, type and description, and adds the background after the first save. A character submitted through the portal keeps all its fields.
