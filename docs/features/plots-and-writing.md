# Plots and writing

The story team writes plots that run through several characters, and tracks how far the writing of each plot and character is.

## Write a plot

Open **Plots** and choose **Add**. Give the plot a title, a summary, the world it belongs to and its writer. Then add a part for each character the plot touches:

- **Private text**: what the story team knows about this character in the plot. Only game masters read it.
- **Player text**: what the player of this character reads.

The plot page lists every character in the plot with both texts. A character's page lists the plots that touch it.

## Writing steps

A plot and a character each have a writing step: draft, ready or approved.

- On a plot, move the step with the buttons on the plot page: **Ready** hands the plot in, **Approve** approves it, **Reopen** sends it back to draft.
- On a character, a game master sets the step and the writer in the character's game state.

The Character roster report counts the characters per writing step and lists the ones not yet approved, with their writer.

A character made before writing steps existed has no step until a game master sets one, so it is not in the list yet.

## Who reads what

| | Game master | Player of the character | Other players |
|---|---|---|---|
| The plot | Reads it | Never gets it | Never gets it |
| A part's player text | Reads it | Reads it | Never gets it |
| A part's private text | Reads it | Never gets it | Never gets it |
| A character's writer and writing step | Reads them | Never gets them | Never gets them |

A part knows its player from its character: each time a part is saved, OpenRegister copies the player account from the character. If a character changes player, save its parts again so the new player reads them.
