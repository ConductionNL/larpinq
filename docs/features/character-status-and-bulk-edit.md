# Character status and bulk edit

Mark who still plays. A character is active, retired or dead. Retired and dead characters stay out of new events, and you change many characters in one go.

## Status

A game master sets the status on the character page, under **Game state & notes**:

- **Active**: the character plays. New characters start active.
- **Retired**: the player stopped playing this character.
- **Dead**: the character died in the game.

The Characters list has a **Status** column, and you filter the list on status.

A retired or dead character is not offered when you add participants to an event. A retired or dead character cannot join a new event through any other screen or the API either. Set the status back to active first. A character can leave an event whatever its status.

Characters made before statuses existed become active when larpinq is updated.

## Edit many characters at once

1. Open **Characters** and tick the characters you want to change.
2. Choose **Edit selected**.
3. Pick a new status, type or world. Leave a field empty to keep it as it is.
4. Choose **Change the selected characters**.

Each character is saved on its own, with the same checks as a single edit. When a character cannot be changed, for example because someone else is editing it, the others are still changed. The dialog lists the characters that were not changed, with the reason.

## Who does what

| | Game master | Player |
|---|---|---|
| See a character's status | Yes | Yes, for characters they can see |
| Set a status | Yes | No |
| Edit selected characters | Yes | Only fields they may change on their own characters |
