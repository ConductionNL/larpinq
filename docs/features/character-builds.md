# Character builds

Try out a different set of skills for a character before you commit to it. A build is a named set of skills, items and conditions for one character. You check it against the rules and the XP the character has, and the character sheet stays as it is.

## Make a build

Open the character and find **Builds**. Choose **Add**, name the build and pick a purpose:

- **Plan**: where you want the character to go, such as Alchemist path.
- **Test**: a build to try something out.
- **Another game**: a build for another campaign or event.

Then pick the skills, items and conditions for the build. You choose from the world of the character.

## Check a build

Open the build and go to the **Check** tab. It shows:

- whether the build fits the rules and the XP of the character,
- how many XP the build is short, if any,
- the requirements the build does not meet,
- the stats the character would have with this build.

The check uses the character's real XP awards and the rules as they are today. It changes nothing. Choose **Check again** after a rule changes.

## Apply a build

A game master opens the build and chooses **Apply to character**. The dialog lists what the character gains and loses. After **Apply to character**, the skills, items and conditions of the character are those of the build.

The normal rules check that change. When the build does not fit, the character stays as it was and the dialog says why. The character's history keeps the old lists.

## Who does what

| | Game master | Player of the character | Other players |
|---|---|---|---|
| See and change the character's builds | Yes | Yes | No |
| Make a build | For any character | For their own characters | No |
| Check a build | Yes | Yes | No |
| Apply a build | Yes | No | No |
