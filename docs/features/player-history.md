# Events a player attended

See which events a player was at, across all their characters and years, on the player's page.

## See a player's events

1. Open **Players** and choose a player.
2. Open the **Events attended** tab in the sidebar.
3. The tab shows how many events the player attended, then every event they were checked in at, newest first, with the character they played and the date the event started. Choose an event to open it.

Only check-ins count: an event where the character was marked as a no-show, or where nobody recorded a check-in, is not listed. Check-ins are recorded on the event's **Check-in** tab.

## Who sees what

- Game masters see the list on every player's page.
- A player sees the list on their own player page: the one whose account is theirs.
- Other players see a note that only game masters and the player can see the list.

Attendance records themselves stay readable by game masters only; the list is put together by Larpinq after it has checked who is asking.
