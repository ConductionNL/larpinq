# Tasks: forms-registration-is-checked-at-binding

- [x] 1.1 Question-to-property mapping on the binding; validator call on save
  - `event.signupFormMapping` (register.d/forms-registration-is-checked-at-binding.json); `SignupFormBinding` hands the mapping and the listener's own values to OpenRegister's `FormDestinationValidatorInterface` against the registration schema; `SignupFormBindingListener` refuses an event write that changes the binding with findings, and one whose binding cannot be judged. Tests: `tests/unit/Service/SignupFormBindingTest.php`, `tests/unit/Listener/SignupFormBindingListenerTest.php`.
- [x] 1.2 `FormSubmissionListener` creates through `FormSubmitService` with idempotency key
  - `FormSubmitWriter` submits the registration through OpenRegister's `FormSubmitServiceInterface` as the submitting account with the app's authority (`FormSubmitter::$appAuthority`, openregister branch `build/forms-registration-is-checked-at-binding`), scope `forms:<form>`, idempotency key `forms-submission:<submission id>`, and Forms' own timestamp as `submittedAt` so a repeated event carries the same object. A refused submit creates nothing and is logged. An OpenRegister without the flag keeps the direct app-authority write. Tests: `tests/unit/Service/FormSubmitWriterTest.php`, `tests/unit/Listener/FormSubmissionListenerTest.php`.
