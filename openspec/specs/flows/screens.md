# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- LrFlows: the flows overview per world; variant of the canonical set, imports OrFlowOverzichtTabel https://identity.conduction.nl/screens/board?id=larpinq/LrFlows
- openregister/OrFlows: the canonical overview this variant follows https://identity.conduction.nl/screens/board?id=openregister/OrFlows
